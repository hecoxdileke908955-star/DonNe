# Web Dọn Nè (CleanHanoi) - Production Ready

Trang web dịch vụ vệ sinh công nghiệp Hà Nội tích hợp đầy đủ tính năng Client + Admin CRM.

## Hướng dẫn đưa lên mạng miễn phí (100% Free):

### Cách 1: Kéo thả lên Netlify (Nhanh nhất - 30 giây)
1. Truy cập: https://app.netlify.com/drop
2. Kéo thả file `index.html` hoặc thư mục giải nén vào ô upload.
3. Nhận ngay đường link web hoạt động 24/7 (ví dụ: `web-don-ne.netlify.app`).

### Cách 2: Đưa lên Vercel
1. Truy cập https://vercel.com
2. Tạo dự án mới và tải file `index.html` lên.

### Thông tin quản trị Admin:
- Nút bấm Admin: Góc trên Topbar hoặc dưới Footer.
- Mật khẩu mặc định: `admin123`
